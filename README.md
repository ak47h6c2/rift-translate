# 峡谷翻译助手

一个面向中国《英雄联盟》外服玩家的 Windows 双向翻译工具。

## 能做什么

- 按住 `F8` 说中文，松开后识别并翻译成简短、自然的游戏英语。
- 翻译完成后无需切出游戏：按 `Enter` 打开聊天、点击输入位置，再按 `F7`，英文会直接填入。
- 助手不会自动按最后的 `Enter`；检查内容后由你实体按 `Enter` 发送。
- Windows 下会同时写入 Unicode 和 ANSI 两种原生文本格式，以兼容自定义游戏输入框。
- 第一次使用时框选游戏聊天区域，之后按 `Ctrl+Shift+L` 截图并翻译可见聊天。
- 翻译结果直接显示在游戏画面右上角的悬浮字幕中，不需要切换窗口。
- 召唤师名称和 Riot ID 保持原样，只翻译实际聊天内容。
- 解释 `diff`、`inting`、`ff15`、`weakside`、`leash` 等缩写和俚语。
- 可以手动粘贴英文聊天，并获得中文含义、语气和建议回复。
- 悬浮字幕不会抢键盘焦点，并且鼠标点击会穿透到游戏。
- `F10` 只在需要改设置或查看完整解释时隐藏/显示主窗口。

工具不会读取游戏内存或注入游戏进程。它只在你明确按 F7 时向前台联盟窗口发送聊天文字所需的键盘事件，并且不会自动按最终 Enter。

## 启动

双击 `启动峡谷翻译助手.bat`。第一次启动会在本项目中安装依赖，时间可能稍长。

也可以在 PowerShell 中手动运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 首次使用

1. 启动助手。
2. 点击“选择聊天区域”。
3. 拖动框住游戏左下角聊天内容；尽量不要包含技能栏、装备和比分。
4. 在游戏中按 `Ctrl+Shift+L`，中文翻译会直接显示在游戏画面右上角。
5. 按住 `F8` 说中文，松开后英文会显示在悬浮字幕中。
6. 在游戏内按 `Enter` 打开聊天并点击输入位置，然后按 `F7` 填入英文；检查后实体按 `Enter` 发送。
7. 第一次在游戏里按 `F8` 或聊天翻译热键时，助手主窗口会自动隐藏。

## 零切换模式

- 建议将游戏显示模式设为“无边框窗口”，悬浮字幕在这种模式下最稳定。
- `F8`：按住说中文；松开后等待悬浮英文。
- `F7`：仅当有一条待输入翻译且联盟位于前台时，将英文填入已经点击聚焦的聊天输入框；不会自动发送。
- `Ctrl+Shift+L`：翻译已经框选的聊天区域，中文结果显示约 12 秒。
- 可在主窗口的热键下拉菜单切换为其他组合键，无需改代码。
- `F10`：需要调整设置时才打开主窗口；再次按下即可隐藏。
- 主窗口中的“预览悬浮字幕”可以在进入游戏前检查显示位置。
- 可在主窗口关闭“游戏内悬浮字幕（零切换）”，恢复只在主窗口查看。

## 2026-09-11 显示与稳定性优化

- 聊天浮窗中的长玩家名完整保留并自动换行，避免挤压译文。
- 最近聊天按有效消息选取，空白识别结果不再挤掉可读消息。
- 翻译返回空值或错误字段类型时安全处理，避免解析崩溃和显示 `None`。

运行本地回归检查（不调用在线翻译）：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## 隐私与费用

- 只有按住 `F8` 期间的录音会被发送用于语音识别。
- 只有你框选的聊天区域在按聊天翻译热键时被截图并发送。
- 翻译采用成本敏感的文本模型；录音采用专用语音转写模型。
- API 密钥只保存在本地 `.env.local`，此文件已被 Git 忽略。

## 故障排查

- “麦克风错误”：在 Windows 设置中允许桌面应用访问麦克风。
- “余额或请求频率受限”：检查 OpenAI Platform 的 Billing 页面。
- 热键没反应：确认游戏没有以比助手更高的管理员权限运行。
- 截图没有识别到聊天：重新框选更紧凑的聊天区域，并确保聊天文字可见。
